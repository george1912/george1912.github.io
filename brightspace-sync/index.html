Brightspace Sync

Pin. Update. Files on your Mac.

Syncs your pinned Brightspace classes into a folder you choose. Optional PDFs when you want them.

Download for Mac How it works

Apple Silicon · macOS · v1.0.3

How to use it

  1. 1

    Pin in Brightspace

    All Courses → Pinned. Only pin this term’s classes.

  2. 2

    Tap Update

    Sign in if asked. The app syncs whatever is pinned.

  3. 3

    Optional PDFs

    Make PDFs for new Office files. LibreOffice required.

Install

  1. Open the DMG → drag Brightspace Sync to Applications.
  2. Open it from Applications (not from the DMG).
  3. If macOS says it’s damaged or blocked, see below — then open again.
  4. Pin classes in Brightspace → tap Update in the app.

If macOS says the app is damaged

This happens on personal (not-yet-notarized) builds. The file is fine — macOS is blocking the download quarantine.

  1. Open Terminal.
  2. Paste this and press Return:
xattr -cr "/Applications/Brightspace Sync.app"
  1. Open Brightspace Sync from Applications again.

Or: right-click the app → Open → confirm once.

Good to know

  • Files stay on your Mac in Synced Courses.
  • PDFs need LibreOffice.
  • Apple Silicon only for this build.
