Install Fox Timer

Easy picture guide. Use Google Chrome.

Before you start Download the ZIP first, then unzip it into a folder you’ll keep (example: Documents → FoxTimer).
1

Open Chrome Extensions

In Chrome’s address bar, type this exactly, then press Enter:

chrome://extensions

↑ Type that into the top bar

2

Turn on Developer mode

Look in the top-right corner. Flip this switch ON.

chrome://extensions
Developer mode

↑ This should be green / ON

3

Click “Load unpacked”

A new button appears after Developer mode is on.

chrome://extensions
Load unpacked

↑ Click this button

4

Choose the Fox Timer folder

Pick the unzipped folder that has the Fox Timer files inside.

FoxTimer
the unzipped folder

Then click Open / Select

5

You’re done!

You should see Fox Timer installed. Open ATI, click the fox icon, set time, press Play.

ITA Lecture Assist Timer Installed · Ready to use

Need to remove it?

  1. Go to chrome://extensions
  2. Find Fox Timer
  3. Click Remove
