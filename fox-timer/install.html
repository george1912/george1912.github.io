Install Fox Timer

Follow the pictures. Use Google Chrome.

Before you start Download the ZIP, then double-click it to unzip. Keep the folder (example: Documents → FoxTimer). Don’t delete it later.
1

Open Chrome Extensions

Click the top bar in Chrome. Type this, then press Enter:

Type: chrome://extensions

Watch · typing demo
chrome://extensions
2

Turn on Developer mode

Look in the top-right. Flip the switch so it turns green / ON.

Developer mode = ON

Watch · toggle demo
Developer mode
3

Click “Load unpacked”

After Developer mode is on, this button appears. Click it.

Click Load unpacked

Watch · click demo
Load unpacked
4

Choose the Fox Timer folder

Select the unzipped folder (the one with the fox files inside), then Open.

Pick the FoxTimer folder → Open

5

Use it while you study

Open ATI → click the fox icon → set minutes → press Play. Then focus on learning.

Press Play, then study

Need to remove it?

  1. Go to chrome://extensions
  2. Find Fox Timer
  3. Click Remove
