Use Cases

What should I pick?

In the ATI Assistant Timer popup there’s a dropdown called “What are you working on?” Pick the one that matches your ATI page — then study without babysitting the mouse.

Best everyday use

Write notes in real time

Open your ATI lesson, start ATI Assistant Timer, then write notes in another window / notebook app. You don’t need to keep clicking the ATI page just to stop it from timing out.

Sample session

You’re in an ATI Lesson. You set ATI Assistant Timer for 45 minutes. Then you take notes in Google Docs / OneNote / paper while the lesson stays awake in the background.

Dropdown: ATI Lesson  ·  Goal: focus on learning, not clicking

Dropdown samples

Each option in the dropdown is a different ATI situation:

ATI Lesson Profile in the dropdown

Use when

You’re in a regular ATI module / lesson with pages and media.

Good for: note-taking, reading slowly, stepping away briefly, letting the lesson advance while you focus.

Video Case Profile in the dropdown

Use when

You’re watching a Video Case and don’t want the page to fall asleep mid-video.

Good for: watching + jotting notes without clicking every few minutes. When time is up, ATI Assistant Timer closes the page for you.

Assessment Profile in the dropdown

Use when

You’re in a quiz / assessment. You still answer every question yourself.

Good for: holding extra time on the last rationale screen while you review notes — then ATI Assistant Timer Continues and finalizes.

Popup Case (Beta) Profile in the dropdown

Use when

You’re in a Real Life / SCORM popup simulation window.

Good for: keeping the popup awake while you think / write notes. When time is up, it tries to click CLOSE. Still Beta — glance at the window at the end.

More sample use cases

Hands off the mouse

Start the timer, put the mouse down, and type notes with both hands. ATI Assistant Timer keeps the session from dying because you stopped clicking.

Study blocks

Set 25–50 minutes, work a focused block, then Pause or End. Treat it like a study timer that also protects your ATI session.

Study Buddy (persistent tips)

Click Open Study Buddy in the popup (after Advanced options). A separate window stays open beside your ATI page with tip carousels you can filter: study methods, time & breaks, fuel & energy, and check learning. Flip Previous / Next or hit New tip to regenerate.

Goal: keep helpful study guidance in view without living in the tiny popup

Review while it runs

Let an ATI Lesson keep moving (or stay awake) while you review flashcards or rewrite notes in another tab.

Study aid built in

ATI Assistant Timer keeps the page from timing out and can shut off at the time you set so you don’t have to babysit the tab — leaving more attention for notes and learning.
